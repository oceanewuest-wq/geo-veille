Le widget 🌸

Les sujets du jour directement sur ton écran d'accueil. Gratuit, iPhone et iPad.

1Installer Scriptable

Une app gratuite qui permet d'afficher des widgets personnalisés.

Ouvrir dans l'App Store

2Ajouter le script

Le plus simple — une fois Scriptable installé, touche ce bouton depuis ton iPhone :

Ajouter le widget à Scriptable

Si le bouton ne fait rien, utilise la méthode manuelle juste en dessous — elle marche à tous les coups.

Méthode manuelle :

  • Copie le code ci-dessous
  • Ouvre Scriptable → bouton + en haut à droite
  • Colle le code, puis touche le titre en haut pour le nommer News

Chargement…

3Poser le widget

  • Reste appuyé sur l'écran d'accueil jusqu'à ce que les icônes bougent
  • Touche + en haut à gauche, cherche Scriptable
  • Choisis la taille (moyen ou grand, c'est le plus lisible) et ajoute-le
  • Touche le widget une fois posé → Modifier le widget → Script : News

Touche le widget pour ouvrir la page complète. iOS décide lui-même de la fréquence de mise à jour (en général dans l'heure).
